Common questions

Do I need to install anything?

No. Students open the game site on any phone or laptop browser, enter their code, and play. Teachers use the same web console — no app, no extension.

What data do you collect from students?

Only their anonymous class code (e.g. S07) and per-question answers. We never see their name, email, school ID, IP, or device fingerprint. See the full Privacy tab in your console.

Can I see what each student answered?

Yes — the Overview tab shows per-student accuracy and per-question mastery. Drill into "Class weak spot" to find which round trips up the class. Reteach buttons auto-generate a follow-up assignment.

What about students who share devices?

Each student picks their own code when joining. Codes are remembered on the same device for the next session — no per-student account needed.

Does it work on slow school Wi-Fi?

Yes. Game bundles are <100 KB. Server responses are cached at the edge. Students on 3G-class networks can play without stalls.
