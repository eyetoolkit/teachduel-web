§ 03 · How it works

Start a class in under 30 seconds.

STEP 01

Pick a game

Open the Console. Choose one of 11 games across three sites. Set class size, time limit, and difficulty — or leave defaults.

STEP 02

Generate room code

One click generates a 6-character code (e.g. ABC123). Copy the link or scan the QR — both work.

STEP 03

Students enter code

Students open the matching site, enter the code, pick their own anonymous handle (S01, S02…). Play begins immediately.

§ 04 · Common questions

Things teachers ask first.

Do I need to install anything?

No. Students open the game site on any phone or laptop browser, enter their code, and play. Teachers use the same web console — no app, no extension, no IT involvement.

What data do you collect from students?

Only their anonymous class code (e.g. S07) and per-question answers. We never see their name, email, school ID, IP, or device fingerprint. See the full Privacy page.

Can I see what each student answered?

Yes. The Overview tab shows per-student accuracy and per-question mastery. Drill into "Class weak spot" to find which round trips up the class. Reteach buttons auto-generate a follow-up assignment.

What about students who share devices?

Each student picks their own code when joining. Codes are remembered on the same device for the next session — no per-student account needed.

Does it work on slow school Wi-Fi?

Yes. Game bundles are under 100 KB. Server responses are cached at the edge. Students on 3G-class networks can play without stalls.

What if my class only has 5 minutes?

MemoryDuel's Knowledge Battle fits in 5 minutes flat: 10 questions × 15 seconds. Tic-Tac-Toe rounds are 30 seconds each. Pick short rounds and you're covered.
